### **Product**

**Caregiver Observed Effectiveness**  
Before selecting this metric, there was discussion about using facial recognition and sentiment analysis on care partners to determine the effectiveness of the dementia portal. However, we realized that this approach is unreliable. This concern is heightened for people experiencing cognitive decline, whose facial expressions may not accurately reflect their thoughts or emotions. Instead, a caregiver will watch the carepartner view the portal’s content, and complete a short feedback form after.  
This metric connects evaluation to the project’s intended purpose. The portal may function correctly while its content or presentation still needs improvement. Caregiver observations can help identify which messages, media, and presentation approaches appear most helpful.

**Unit Test Pass Rate**  
The unit test pass rate measures the percentage of executed unit tests that succeed. We will record the pass rate using this formula:

$Unit\ Test\ Pass\ Rate\ =\ \frac{Passed\ Unit\ Tests}{Total\ Number\ of\ Tests}✕\ 100$

This metric is valuable because Familiar Faces builds on an existing codebase. Changes to new requirements or infrastructure can unintentionally affect existing behavior. Unit test results provide repeatable feedback that helps us identify these mistakes early.

**Clicks per Operation/ Time per Operation**  
There has been much discussion regarding the carepartner’s interaction with the application. Given the unpredictable nature of dementia, the application needs to master accessibility. While it is unknown exactly what features the carepartners would have access to, a metric worth keeping track of is click per operation (or time per operation). This metric would help assess how much difficulty the carepartner is having with the application.
